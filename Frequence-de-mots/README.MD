# Fréquence de mots

Projet Python simple pour analyser la fréquence des mots dans un texte.

## Description

Ce projet lit un fichier texte ou une chaîne de caractères, compte la fréquence d'apparition des mots et affiche les résultats triés par ordre décroissant.

## Prérequis

- Python 3

## Installation

1. Cloner le dépôt ou copier les fichiers du projet.
2. Placer le script Python et le fichier texte dans le même dossier.

## Utilisation

Exécuter le script avec Python :

```bash
python main.py
```

ou, si le projet propose une interface en ligne de commande :

```bash
python main.py chemin/vers/fichier.txt
```

## Fonctionnalités

- Lecture d'un texte en entrée
- Nettoyage des mots (suppression de la ponctuation)
- Comptage des mots
- Tri des résultats par fréquence

## Objectif

Ce projet sert à apprendre la manipulation de texte, l'analyse de données simples et l'utilisation de dictionnaires en Python.

<i>Ce projet a été réalisé avec termux sur un smartphone Galaxy A13.<i/>
